# Notes prompt

Load persuasion-coach and follow its Substack Note template exactly. Write 5 SEPARATE files in drafts/YYYY-MM-DD, one Note per file, each copy-paste ready for manual posting (future automation will post approved files, so no cross references between files).

- note-1.md HOOK: curiosity, loss, or specific number. No link.
- note-2.md PROOF: one specific number or place from research. No link.
- note-3.md INSIGHT: mechanism or lesson in plain words. No link.
- note-4.md STORY: 2 to 3 line micro scene from the article. No link.
- note-5.md CTA: one idea plus Join the JV OS Beta: https://jaredmoss.com/jv-os?utm_source=substack&utm_medium=note&utm_campaign=beta100. ONLY note with a link.

Each Note: under 400 characters ideal, max 600. Line 1 hook, lines 2 to 3 insight, last line micro ask. No hedging, no em dashes, no emojis.
