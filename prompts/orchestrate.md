# Solo runbook, WEEKLY edition (used by the Thursday GitHub Action, single session, no subagents)

You are the entire content team in ONE session. Read AGENTS.md, MEMORY.md, BOARD.md To Do Today first. Never call the Task tool. Never delegate. Do all phases yourself inline. Subagents are disabled in this repo for a reason: one session means far fewer billed requests, which is what keeps the free key alive.

Hard ban: never edit .opencode, skills, prompts, opencode.json, or .github/workflows. Improvement ideas go in platform-brief.md as recommendations only.

Request budget, hard limits. Exceed these and the run dies:
- Max 6 websearch plus webfetch calls for the whole run. Research from them plus the style anchors, then stop searching.
- Comic phase uses no web at all: it reads only the finished article.
- Batch independent file reads and writes in single blocks. Fewer turns is faster and safer than many small turns.
- Never run the same failing call twice. On any API 429, wait 60 seconds with sleep 60, then continue. Max 2 waits, then write from what you have.

Rotation: run `date +%V` for the ISO week number. Set N equals week number mod 10, where 0 means W10. Cinematic is primary: that week's set comes from prompts/cinematic/00-noir-50-index.md week table W01 to W10 (W01 is the locked weekly 5: I05, I13, teal v3, I06, I12, video V02). prompts/manual-60/S01-S10 stays as fallback variety only. Every panel names its cinematic ID. Every image and video prompt ends with the LOCK from prompts/cinematic/10-image-bank.md or 20-video-bank.md. Never paste Melies verbatim alone, scrub fedora, smoke, cards, gambling first. Never put brand words in a generator prompt, brand type is layout only.

Phases, in order, all inline:
1. Research: 3 light tracks, 2 searches each max. (a) Nationwide JV and JV compliance news. (b) Utah real estate deals. (c) Top Substack real estate posts of the week with titles plus authors. Write drafts/YYYY-MM-DD/research-brief.md with one cited line per item. The article must reference at least one item per track.
2. Ideate: 3 titles under 70 chars, subtitle under 140, hook for first 2 lines, outline, CTA https://jaredmoss.com/empire twice.
3. Article: load persuasion-coach then humanize-writing. Write 1000 to 1600 words plus metadata block to drafts/YYYY-MM-DD/article-draft.md. Hook in first 3 lines. No hedging, no em dashes, no emojis.
4. Comic arc: load comic-arc skill. Read drafts/YYYY-MM-DD/article-draft.md and write drafts/YYYY-MM-DD/comic-pack.md with cast sheet, three act beats, 5 panel prompts each naming its cinematic ID from this week's set, and the complete 10 second single-scene video prompt built from this week's V pick plus the video LOCK. No web. Max 4 requests for this phase.
5. Notes: load persuasion-coach Note template. Write 5 SEPARATE files note-1.md through note-5.md mapped Mon to Fri to buyer types Director, Relator, Intellectual, Validator, Executive, using each type's drives plus language bank plus REQUIRED buyer-matched transformation payoff (Delta model: mechanism plus what life looks like after, exact phrase "so you can" allowed but not required). Copy stays human persuasion work, panel art comes from comic-pack.md, do not redescribe art in the Note files. Header of each file names its post day plus buyer type. Each under 400 chars ideal, max 600, one idea, copy-paste ready for manual drip posting. Link only on note-5 with UTM.
6. Visual: load substack-visual plus design-architect. Copy assets/cover-template.svg to drafts/YYYY-MM-DD/cover.svg with the week hook (cover stays flat vector editorial, never noir). Render drafts/YYYY-MM-DD/cover.png with python3 scripts/render-cover.py. Write image-prompt-pack.md with 5 sections from this week's cinematic image IDs plus character casting from drafts/YYYY-MM-DD/comic-pack.md, day mapping slot 1 Mon Jared solo, slot 2 Tue Jared plus ally, slot 3 Wed proof object only, slot 4 Thu ally foreground, slot 5 Fri hero over villain, every section carrying the style line, faceless hero no hat, grayscale people, exactly one spot color per character, the full vice ban with cards dice lighters, and the text ban with logos badges captions. Write video-script-pack.md as ONE complete 10 second single scene max built from this week's V pick: scene plus one camera move plus speed plus duration plus purpose, plus the video LOCK, end card in layout, never rendered brand text. Protest Guerrilla only, Carter One and The Last Shuriken banned.
7. Outreach: fetch the rising real estate bestsellers leaderboard plus one recent post each from 3 to 5 names. Write drafts/YYYY-MM-DD/dm-pack.md with one personalized DM draft each: one line on their post, one line on your angle, one collaboration ask. These are pasted and sent by hand. Never attempt automated sending.
8. Platform: note anything new on Substack this week (Notes, video, paywalls, algorithm, editor). Write drafts/YYYY-MM-DD/platform-brief.md with concrete recommendations for our agents, prompts, or skills. Recommendations only, apply nothing.
